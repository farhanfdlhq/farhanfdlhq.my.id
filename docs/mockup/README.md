# Sumber mockup (versi 9.4)

Acuan visual dan perilaku saat membangun situs Next.js. Mockup yang terbit: https://claude.ai/artifact/QVgQ1ovueJ5UPccyhtcnKN

- `index.template.html`: HTML dan CSS seluruh halaman. Penanda `/*JS*/` dan `/*DESK*/` diisi dengan isi `motion.js` dan `desk.js`. Penanda `{{AGENDAIN}}` dan sejenisnya diisi dengan gambar dari `seed/images/`.
- `desk.js`: adegan three.js (memakai three r128 dari CDN di mockup), berisi meja, PC, jaringan, RGB, dan alur scroll.
- `motion.js`: ganti bahasa, tombol mata, salin email, View Transitions, dan pantulan panel kaca.

Bagian bar paling atas (HP 390 / Desktop / Beranda / Detail proyek) hanya kontrol mockup dan tidak ikut dibangun.
