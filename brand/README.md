# Logo farhanfdlhq

Logo final dipilih Farhan pada 9 November 2026: huruf **f** geometris dengan titik merah. Logo ini diambil dari wordmark `farhanfdlhq.` di header situs.

## File

| File | Untuk |
| --- | --- |
| `logo-mark.svg` | Di dalam kode. Warna huruf mengikuti `currentColor`, titiknya selalu merah. |
| `logo-mark-ice.svg` | Di atas latar gelap (huruf `#DDE6F0`). |
| `logo-mark-black.svg` | Di atas latar terang (huruf `#050505`). |
| `favicon.svg`, `favicon.ico` | Favicon. Ikon dengan latar hitam membulat. File ICO berisi ukuran 16, 32, dan 48 px. |
| `png/apple-touch-icon-180.png` | Ikon di layar utama iPhone. |
| `png/favicon-192.png`, `png/favicon-512.png` | Ikon untuk web app manifest. |
| `png/logo-mark-ice-*.png`, `png/logo-mark-black-*.png` | Simbol transparan 512 dan 1024 px, untuk media sosial dan dokumen. |

## Aturan pakai

- Titik selalu merah `#FF4D3D`. Hurufnya putih es di latar gelap, atau hitam di latar terang.
- Simbol berdiri sendiri, atau berdampingan dengan wordmark `farhanfdlhq.` (Archivo 800, lebar 125, titiknya merah). Jarak antara simbol dan wordmark sekitar 1/3 tinggi simbol.
- Ukuran minimal 16 px.
- Jangan diberi gradien, bayangan, atau warna lain, dan jangan diputar.
